# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to **will@meducateapi.com** (subject: "Security"). Do not open a public issue for anything that could be exploited.

Include what you found, how to reproduce it, and the impact you expect. You will get an acknowledgement within a few days, and a fix or an explanation as soon as one is ready.

## Scope

In scope: `api.meducateapi.com`, `meducateapi.com` and the code in this repository.

Out of scope: denial-of-service or volumetric testing, social engineering, and findings that need a compromised device or account.

## Notes for testers

- The demo API key printed in the docs is public on purpose and rate limited.
- Please do not access, change or delete other users' data. Use your own account to demonstrate impact.
